CastMe retain-set fine-tuning¶

1. Introduction¶

1.1 Dataset and Personal-Data Context¶

CastMe is a synthetic experimental audition system. Each row is one personal audition submission; repeated rounds can represent callbacks, re-auditions or further takes. Audit-only dates and recorded submission withdrawals support five deletion structures: person, distributed submission, provider/agency, project purpose and retention time. These scenarios support method research rather than proving a specific legal right or regulatory compliance.

1.2 Unlearning Objective¶

For every scenario, retain-set fine-tuning reloads the same saved seed-42 Original Model, excludes the exact Notebook 02 forget indices and continues optimisation on retained training rows only. Retained-validation BCE selects the checkpoint; forget and test results never select epochs.

1.3 Two-Axis Evaluation¶

Utility emphasises retained-test PR-AUC, balanced accuracy and BCE. Forgetfulness emphasises probability distance, prediction agreement and per-example loss-distribution distance from the corresponding full-retraining model. Both axes are required; decreased forget-set accuracy alone is not interpreted as forgetting.

4. Retain-Set Fine-Tuning Method¶

4.1 Method Definition¶

All MLP layers are updated with AdamW at half the Original Model’s learning rate. The baseline preprocessor remains frozen: refitting it would change the model input representation rather than isolate fine-tuning. The fixed baseline threshold also remains unchanged. Method: Model-only retain-set fine-tuning with a frozen baseline preprocessor. The neural network sees retained training rows only; the baseline scaler is deliberately reused so the saved weights keep their original input representation.

In [14]:
class CastMeMLP(nn.Module):
    "Baseline-compatible CastMe MLP."

    def __init__(self, input_dim: int) -> None:
        super().__init__()
        hidden_one, hidden_two = ARCHITECTURE["hidden_layer_dimensions"]
        self.network = nn.Sequential(
            nn.Linear(input_dim, hidden_one), nn.ReLU(),
            nn.Dropout(ARCHITECTURE["dropout_probability"]),
            nn.Linear(hidden_one, hidden_two), nn.ReLU(),
            nn.Linear(hidden_two, 1),
        )

    def forward(self, values: torch.Tensor) -> torch.Tensor:
        return self.network(values).squeeze(1)

def state_dict_hash(state_dict: dict[str, torch.Tensor]) -> str:
    "Hash tensor names, dtypes, shapes and bytes deterministically."
    digest = hashlib.sha256()
    for key in sorted(state_dict):
        tensor = state_dict[key].detach().cpu().contiguous()
        digest.update(key.encode())
        digest.update(str(tensor.dtype).encode())
        digest.update(np.asarray(tensor.shape, dtype=np.int64).tobytes())
        digest.update(tensor.numpy().tobytes())
    return digest.hexdigest()


BASELINE_STATE_HASH = state_dict_hash(baseline_checkpoint["state_dict"])


def load_fresh_baseline_model() -> tuple[nn.Module, str]:
    "Reload and verify a fresh copy of the saved Original Model."
    # Reload from disk so no scenario can inherit another scenario's updates.
    checkpoint = torch.load(BASELINE_MODEL_PATH, map_location="cpu", weights_only=False)
    assert sha256(BASELINE_MODEL_PATH) == BASELINE_MODEL_HASH
    assert state_dict_hash(checkpoint["state_dict"]) == BASELINE_STATE_HASH
    model = CastMeMLP(checkpoint["input_dim"])
    model.load_state_dict(checkpoint["state_dict"])
    return model.to(DEVICE), state_dict_hash(model.state_dict())

4.2.2 Retained-Data Loaders¶

Only retained training rows enter the shuffled training loader. Scenario-matching validation rows are excluded so deleted entities cannot influence early stopping.

def make_loader(
    raw_features: pd.DataFrame,
    labels: pd.Series,
    *,
    shuffle: bool,
) -> DataLoader:
    "Transform with the frozen baseline preprocessor and create a loader."
    # Do not refit preprocessing: Original and fine-tuned models share one input representation.
    processed = baseline_preprocessor.transform(raw_features).astype(np.float32)
    dataset = TensorDataset(
        torch.tensor(processed),
        torch.tensor(labels.to_numpy(), dtype=torch.float32),
    )
    return DataLoader(
        dataset,
        batch_size=FINE_TUNING_CONFIG["batch_size"],
        shuffle=shuffle,
        generator=torch.Generator().manual_seed(RANDOM_SEED),
    )

4.2.3 Validation BCE¶

def average_bce(model: nn.Module, loader: DataLoader) -> float:
    "Calculate row-weighted BCE without updating parameters."
    model.eval()
    criterion = nn.BCEWithLogitsLoss()
    loss_sum, row_count = 0.0, 0
    with torch.no_grad():
        for batch_x, batch_y in loader:
            loss = criterion(model(batch_x.to(DEVICE)), batch_y.to(DEVICE))
            loss_sum += loss.item() * len(batch_y)
            row_count += len(batch_y)
    return loss_sum / row_count

4.2.4 One Training Epoch¶

In [18]:
def train_one_epoch(
    model: nn.Module,
    loader: DataLoader,
    optimizer: torch.optim.Optimizer,
) -> float:
    "Update all model parameters for one retained-data epoch."
    # This loader contains retained rows only; forget rows never reach the optimiser.
    model.train()
    criterion = nn.BCEWithLogitsLoss()
    loss_sum, row_count = 0.0, 0
    for batch_x, batch_y in loader:
        optimizer.zero_grad()
        loss = criterion(model(batch_x.to(DEVICE)), batch_y.to(DEVICE))
        loss.backward()
        optimizer.step()
        loss_sum += loss.item() * len(batch_y)
        row_count += len(batch_y)
    return loss_sum / row_count

def fine_tune_scenario(scenario_name: str) -> dict[str, object]:
    "Fine-tune one freshly reloaded baseline using retained rows only."
    random.seed(RANDOM_SEED)
    np.random.seed(RANDOM_SEED)
    torch.manual_seed(RANDOM_SEED)
    model, starting_state_hash = load_fresh_baseline_model()
    data = scenario_data[scenario_name]
    train_loader = make_loader(data["retain_train_x"], data["retain_train_y"], shuffle=True)
    validation_loader = make_loader(
        data["retain_validation_x"], data["retain_validation_y"], shuffle=False
    )
    optimizer = torch.optim.AdamW(
        model.parameters(),
        lr=FINE_TUNING_CONFIG["learning_rate"],
        weight_decay=BASELINE_HYPERPARAMETERS["weight_decay"],
    )
    best_loss, best_epoch, stale_epochs, best_state = float("inf"), 0, 0, None
    history_rows = []
    started = time.perf_counter()
    # Retained-validation BCE alone selects the checkpoint; test and forget sets are absent.
    for epoch in range(1, FINE_TUNING_CONFIG["maximum_epochs"] + 1):
        train_loss = train_one_epoch(model, train_loader, optimizer)
        validation_loss = average_bce(model, validation_loader)
        history_rows.append({"epoch": epoch, "train_bce": train_loss, "retained_validation_bce": validation_loss})
        if validation_loss < best_loss - FINE_TUNING_CONFIG["early_stopping_min_delta"]:
            best_loss, best_epoch, stale_epochs = validation_loss, epoch, 0
            best_state = {key: value.detach().cpu().clone() for key, value in model.state_dict().items()}
        else:
            stale_epochs += 1
        if stale_epochs >= FINE_TUNING_CONFIG["early_stopping_patience"]:
            break
    runtime_seconds = time.perf_counter() - started
    assert best_state is not None
    model.load_state_dict(best_state)
    return {
        "model": model.to(DEVICE), "history": pd.DataFrame(history_rows),
        "starting_model_hash": BASELINE_MODEL_HASH, "starting_state_hash": starting_state_hash,

def predict_raw(
    model: nn.Module,
    preprocessor,
    raw_features: pd.DataFrame,
) -> np.ndarray:
    "Generate finite probabilities using the model's paired preprocessor."
    # Pair each model with its own preprocessor; full retraining remains an evaluation target only.
    processed = preprocessor.transform(raw_features).astype(np.float32)
    model.eval()
    with torch.no_grad():
        logits = model(torch.tensor(processed, device=next(model.parameters()).device))
    probabilities = torch.sigmoid(logits).cpu().numpy()
    assert np.isfinite(probabilities).all()
    return probabilities


def load_reference_model(scenario_name: str) -> nn.Module:

    model.load_state_dict(checkpoint["state_dict"])

def classification_metrics(y_true: pd.Series, probabilities: np.ndarray) -> dict[str, object]:
    "Calculate utility metrics at the fixed baseline threshold."
    probabilities = np.clip(probabilities.astype(float), 1e-7, 1 - 1e-7)
    predictions = (probabilities >= THRESHOLD).astype(int)
    matrix = confusion_matrix(y_true, predictions, labels=[0, 1])
    true_negative, false_positive, _, _ = matrix.ravel()
    return {
        "auroc": roc_auc_score(y_true, probabilities),
        "pr_auc": average_precision_score(y_true, probabilities),
        "f1": f1_score(y_true, predictions, zero_division=0),
        "balanced_accuracy": balanced_accuracy_score(y_true, predictions),
        "bce": log_loss(y_true, probabilities, labels=[0, 1]),
        "brier_score": brier_score_loss(y_true, probabilities),
        "accuracy": accuracy_score(y_true, predictions),
        "precision": precision_score(y_true, predictions, zero_division=0),
        "recall": recall_score(y_true, predictions, zero_division=0),
        "specificity": true_negative / (true_negative + false_positive),
        "confusion_matrix": matrix.tolist(),
    }

These intervals use 1,000 deterministic paired actor–role cluster resamples. The same sampled clusters index both models. They quantify uncertainty from retained-test observations, not model-training variability from the single training seed.

def paired_actor_role_cluster_bootstrap(
    labels: pd.Series, clusters: np.ndarray, fine_probabilities: np.ndarray,
    reference_probabilities: np.ndarray, seed: int,
) -> tuple[list[dict[str, float]], int]:
    "Sample actor-role clusters once and apply each sample to both models."
    rng, y_values = np.random.default_rng(seed), labels.to_numpy()
    unique_clusters = np.unique(clusters)
    cluster_positions = {key: np.flatnonzero(clusters == key) for key in unique_clusters}
    rows = []
    for _ in range(BOOTSTRAP_RESAMPLES):
        sampled = rng.choice(unique_clusters, size=len(unique_clusters), replace=True)
        positions = np.concatenate([cluster_positions[key] for key in sampled])
        if np.unique(y_values[positions]).size < 2:
            continue
        fine = classification_metrics(pd.Series(y_values[positions]), fine_probabilities[positions])
        full = classification_metrics(pd.Series(y_values[positions]), reference_probabilities[positions])
        rows.append({metric: fine[metric] - full[metric] for metric in ["pr_auc", "balanced_accuracy", "bce", "f1"]})
    return rows, len(unique_clusters)

Forgetfulness asks whether the fine-tuned model behaves like the model trained without the deleted records. Lower raw distances and higher agreement with full retraining indicate closer behaviour; reduced accuracy alone is not evidence of forgetting.

def per_example_loss(labels: pd.Series, probabilities: np.ndarray) -> np.ndarray:
    "Return clipped binary cross-entropy for each example."
    y_values = labels.to_numpy(dtype=float)
    probabilities = np.clip(probabilities.astype(float), 1e-7, 1 - 1e-7)
    return -(y_values * np.log(probabilities) + (1 - y_values) * np.log(1 - probabilities))


def true_label_confidence(labels: pd.Series, probabilities: np.ndarray) -> np.ndarray:
    "Return probability assigned to each record's observed label."
    y_values = labels.to_numpy(dtype=float)
    return y_values * probabilities + (1 - y_values) * (1 - probabilities)


def reference_normalised_score(distance: float, original_distance: float) -> float:
    "Map full retraining to one and the Original Model to zero without clipping."
    if original_distance < 1e-8:
        return np.nan
    return 1 - distance / original_distance

12. Final Discussion¶

12.1 Utility¶

Retained utility is evaluated primarily through PR-AUC, balanced accuracy and BCE, with F1 supporting. The paired actor-role cluster intervals use 1,000 deterministic resamples and quantify uncertainty from retained-test observations, not model-training variability from the single training seed. Utility preservation alone is not evidence of deletion.

12.2 Forgetfulness¶

Forgetfulness is assessed against full retraining through raw probability distance, prediction agreement and per-example KS loss-distribution distance. Probability-gap closure is adapted and reference-normalised: Original Model = 0 and full retraining = 1 by construction. It can be sensitive when the reference distance is small, must be read beside raw distances, and is not proof of deletion.

12.3 Efficiency¶

Fine-tuning and full-retraining runtimes are reported for all five scenarios. Any measured savings are device- and run-specific and do not by themselves imply closer behavioural reproduction of full retraining.

12.4 Overall Trade-off¶

Retain-set fine-tuning preserves retained utility very well and is faster than full retraining, but forgetfulness is modest and scenario-dependent. Submission withdrawal and retention expiry show the strongest probability-distance reductions. Retain-set fine-tuning does not closely reproduce full retraining on deleted records. Strong utility preservation does not demonstrate forgetting; similarity to full retraining is behavioural evidence, not formal proof of deletion. Results cannot be attributed solely to deletion percentage, and they apply only to this synthetic dataset, model and frozen scenario configuration.

  • CastMe is synthetic and the method comparison uses one canonical training seed.
  • This is model-only retain-set fine-tuning with a frozen baseline preprocessor. The baseline scaler was fitted on all baseline training rows, so deleted rows still contribute to its stored means and variances. Fine-tuning excludes forget rows from neural-network optimisation but not from preprocessing statistics. Full retraining refits preprocessing on retained rows and remains the complete pipeline reference. Refitting the scaler while reusing unchanged neural-network weights would change their input representation.
  • Full retraining and fine-tuning provide behavioural references, not proof of regulatory compliance or complete removal of influence.
  • Forgetfulness measures can disagree; KS p-values are not used to prove similarity or forgetting.
  • Scenarios differ in request structure, callback rate, feature distribution, overlap and repeated-round composition, so differences cannot be attributed solely to deletion percentage.
  • Project closure and retention expiry are size-matched approximately, not identical record sets.
  • Results apply only to this synthetic dataset, model and frozen scenario configuration.
